# Grade 7 Art unit-1 Lesson

## Open the site

Open `index.html` in a browser, or serve this folder with a local web server. Bootstrap is loaded from the project files, so no CDN connection is needed for the layout or navigation.

## Pages

- `index.html` — home page and lesson cards.

## Project files

- `css/bootstrap.min.css` — local Bootstrap stylesheet.
- `js/bootstrap.bundle.min.js` — local Bootstrap JavaScript bundle, including responsive navbar support.
- `style.css` — site styling.
- `script.js` — lesson card navigation and answer feedback.
- `assets/` — font and images assets.

Keep the relative folder structure when moving or hosting the site so the local styles, scripts, font, and model continue to load.
